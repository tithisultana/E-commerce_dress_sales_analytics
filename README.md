# E-Commerce Dress Sales Analytics Project

## Files

- `dress_sales.csv` = the only dataset used by all notebooks
- `01_E-Commerce_Dress_Sales_EDA.ipynb` = Data Analysis / EDA
- `02_E-Commerce_Dress_Sales_Prediction.ipynb` = Linear Regression + Random Forest
- `03_E-Commerce_Customer_Segmentation.ipynb` = K-Means customer segmentation
- `data_dictionary.md` = column explanations

## Dataset

- 10,000 transactions
- 30 products
- 2,461 customers
- Date range: 2025-01-01 to 2026-08-31

## Models

- Linear Regression
- Random Forest Regression
- K-Means Clustering
